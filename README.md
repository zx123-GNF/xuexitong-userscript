# 学习通（超星）自动答题器

> **当前最新版本：`v3.4.1`**
> 主文件：`学习通-DeepSeek自动答题器.user.js`
> 每个历史版本在 git 里都有对应的 commit 和 tag。

---

## 这是什么

一个篡改猴（Tampermonkey）用户脚本，用在学习通（超星）的章节学习页：

- **题库优先**：先查题库，命中直接搬答案；查不到才调 DeepSeek
- 自动识别题目（单选 / 多选 / 判断 / 填空，简答题可开关），字体加密题自动截图走视觉识别
- 自动提交、自动进入下一个小节
- 视频任务点**不碰播放器**，先点开同小节的「2 章节测验」任务点，答完再点「下一节」
- 找不到下一节 → 判定本课程结束，停在当前页

## ⚠️ 两个高频问题怎么排查（先看这里）

### 1. 题库"全都找不到"

**第一步：点面板上的 `🔌 测试题库`**，日志会明确告诉你是哪一类：

| 日志 | 含义 | 怎么办 |
|---|---|---|
| `免费题库可用（网课小助手）：…` | 接口正常 | 若仍查不到，是这门课的题不在免费库里 → 靠本地库积累或等 AI |
| `题库查询失败：网络错误/请求超时/HTTP xxx` | **请求根本没成功** | 检查能否打开 `https://cx.icodef.com`；Tampermonkey 是否拦了跨域；换网络重试 |
| `题库查询失败：响应非 JSON：…` | 拿回来的是网页不是数据 | 大概率被运营商/防火墙劫持，贴日志给助手 |
| `题库查询失败：流控(code:-2)` | 触发 1 并发限制 | 等 10 秒自动冷却，或调大间隔 |
| `题库未收录(code:-1)` | 接口正常，但这道题它没有 | 正常现象，会自动交给 AI |

启动后日志里还会打印 **`题库查询文本示例：…`**，可以据此确认发出去的题干是不是正常的（不该带选项内容）。
连续 2 次请求失败会自动放弃题库、本轮全交给 AI，不会一直卡着。

> **v3.4.1 修复**：上一版「🔌 测试题库」在没点启动时直接返回「已停止」（耗时 1ms），**根本没发出请求**，
> 所以看起来像"题库全都查不到"。现在测试按钮不再依赖任务是否启动。

### 2. 多选题"点了选不上"

v3.4.0 针对三个最可能的原因做了修复：

- **连点抵消**：同一个选项短时间内被点两次 = 刚选上又被取消。现在 600ms 内不会重复点。
- **节点失效**：学习通新版是 JS 渲染，点一个选项后整段可能重新渲染，之前缓存的节点就失效了，
  后续点击等于点在空气上。现在每次点击前都会确认节点还在，失效就重新采集。
- **识别器漏判导致反复点击**：不再只看"单个选项认不认得出"，而是比对**整题选中态有没有变化**；
  只要点击产生了变化就认为生效，不会再去点第二次。

如果还是不行：**点 `🔬 导出题目 HTML`**，它会打印每道题的真实结构，包括
`li.class` / `aria-checked` / `aria-pressed` / 隐藏答案框的 value / 字母标记元素，
把复制出来的内容发出来就能精确定位。

## 题库策略

检索顺序：

```
本地题库 → 自定义题库 → 免费公开题库 → DeepSeek 兜底
```

| 层 | 说明 | 默认 |
|---|---|---|
| **本地题库** | 自动收录答过的题（存「选项文本」，选项顺序变了也能对上），跨学习通子域共享 | 开 |
| **自定义题库** | 填一个兼容 `POST /api/search` 的地址（`chaoxing-toolkit` 协议），留空则跳过 | 未配置 |
| **免费公开题库** | 社区脚本「超星学习通满分助手」同款接口 `cx.icodef.com`，免 token | 开 |
| **AI** | DeepSeek，前三层都没命中才用 | 已有 |

### 关于免费公开题库（务必知道）

- 它**不是**学习通官方题库。学习通没有公开的官方题库/API。
- 实测（2026-10）：免 token 可直接用，公共课题目抽样命中约 5/6，返回 `{"code":1,"data":"答案1#答案2"}`。
- **有 1 并发限制**：必须严格串行 + 留间隔，否则立刻 `code:-2 触发流控`。脚本已做串行 + 4s 间隔 + 10s 冷却。
- 是第三方接口，**可能随时失效、也可能返回错误答案**。面板可随时取消勾选「免费题库」退回纯 AI。
- 代价：一节课题越多，题库检索越慢（每题约 4s）。已限制单轮最多查 24 题。

## 快速开始

1. 浏览器安装 **篡改猴（Tampermonkey）**扩展。
2. 篡改猴 → 打开原脚本 → **全选清空** → 粘贴本目录下 `学习通-DeepSeek自动答题器.user.js` 全部内容 → `Ctrl+S`。
   > ⚠️ **不要新旧两个脚本同时安装**，会双重点击同一道题。
3. 打开学习通课程页，面板里填 DeepSeek API Key（`sk-` 开头）→「保存」。
4. 建议先点 **🔌 测试题库** 确认连通性。
5. 点「▶ 启动」。第一次请求时篡改猴会弹跨域授权，选「始终允许」。

## 面板按钮

| 按钮 | 作用 |
|---|---|
| ▶ 启动 / ■ 停止 | 开始 / 停止自动答题 |
| 🔍 诊断本题 | 打印某道题的选项状态、绑定事件 |
| 🧭 扫描自检 | 列出 frame、是否视频页、未完成任务点标签、下一节候选及排序理由 |
| 🔬 导出题目 HTML | 前 3 道题的真实 DOM + 每个选项的 class/aria/隐藏答案框状态 |
| 🎯 拾取「下一节」/「章节测验」 | 手动绑定按钮，优先级最高 |
| 🔌 测试题库 | 测题库连通性，并明确报告失败原因 |
| 导出 / 导入 / 清空 | 本地题库 JSON 备份、恢复、清空 |
| 题库优先 / 免费题库 / 本地库 | 三个独立开关 |

日志里每道题都会标注来源：`[本地题库]`、`[网课小助手]`、`[AI]`。
