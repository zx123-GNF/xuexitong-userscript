# 学习通（超星）自动答题器

> **当前最新版本：`v3.3.0`**
> 主文件：`学习通-DeepSeek自动答题器.user.js`
> 每个历史版本在 git 里都有对应的 commit 和 tag（`v2.1.0` / `v3.0.0` / `v3.1.0` / `v3.2.0` / `v3.3.0`）。

---

## 这是什么

一个篡改猴（Tampermonkey）用户脚本，用在学习通（超星）的章节学习页：

- **题库优先**：先查题库，命中直接搬答案；查不到才调 DeepSeek
- 自动识别题目（单选 / 多选 / 判断 / 填空，简答题可开关），字体加密题自动截图走视觉识别
- 自动提交、自动进入下一个小节
- 视频任务点**不碰播放器**，先点开同小节的「2 章节测验」任务点，答完再点「下一节」
- 找不到下一节 → 判定本课程结束，停在当前页

---

## 题库策略（v3.3.0 新增）

检索顺序：

```
本地题库 → 自定义题库 → 免费公开题库 → DeepSeek 兜底
```

| 层 | 说明 | 默认 |
|---|---|---|
| **本地题库** | 自动收录答过的题（存「选项文本」，选项顺序变了也能对上），跨学习通子域共享 | 开 |
| **自定义题库** | 填一个兼容 `POST /api/search` 的地址（`chaoxing-toolkit` 协议），留空则跳过 | 未配置 |
| **免费公开题库** | 社区脚本「超星学习通满分助手」同款接口 `cx.icodef.com`，免 token | 开 |
| **AI** | DeepSeek，前三层都没命中才用 | 已有 |

### 关于免费公开题库（务必知道）

- 它**不是**学习通官方题库。学习通并没有公开的官方题库/API，题目来自教材配套题库和各校自建题库，都不对外开放。
- 实测（2026-10）：**免 token 可直接用，抽样命中约 5/6**，返回格式 `{"code":1,"data":"答案1#答案2"}`。
- **有 1 并发限制**：必须严格串行 + 留间隔，否则立刻返回 `code:-2 触发流控`。脚本已做串行队列 + 最小间隔 4s + 流控冷却 10s。
- `code:-1` 表示未收录，会自动降级给 AI。
- 这是个第三方接口，**可能随时失效、也可能返回错误答案**。面板上可以随时关掉（取消勾选「免费题库」），关掉后就是纯 AI 答题。
- 代价：一节课题越多，题库检索越慢（每题约 4s）。已限制单轮最多查 24 题。

## 快速开始

1. 浏览器安装 **篡改猴（Tampermonkey）**扩展。
2. 打开篡改猴 → 新建脚本（或打开原来那个脚本）→ **全选清空** → 粘贴本目录下
   `学习通-DeepSeek自动答题器.user.js` 的全部内容 → `Ctrl+S` 保存。
   > ⚠️ **不要新旧两个脚本同时安装**，会双重点击同一道题。
3. 打开学习通课程页面，右上角面板里填入 DeepSeek API Key（`sk-` 开头），点「保存」。
4. 建议先点一次 **🔌 测试题库** 确认网络能连上（可选）。
5. 点「▶ 启动」。第一次请求时篡改猴会弹跨域授权，选「始终允许」。

## 面板按钮

| 按钮 | 作用 |
|---|---|
| ▶ 启动 / ■ 停止 | 开始 / 停止自动答题 |
| 🔍 诊断本题 | 打印某道题的选项状态、绑定事件，用于排查"点了没反应" |
| 🧭 扫描自检 | 列出所有 frame、是否视频页、**未完成任务点标签**、**下一节候选及排序理由** |
| 🔬 导出题目 HTML | 把前 3 道题的真实 DOM 复制到剪贴板；多选/题库出问题就点它 |
| 🎯 拾取「下一节」/「章节测验」 | 手动绑定按钮，优先级最高，改版时用 |
| 🔌 测试题库 | 测免费题库/自定义题库通不通 |
| 导出 / 导入 / 清空 | 本地题库的 JSON 备份、恢复、清空 |
| 题库优先 / 免费题库 / 本地库 | 三个独立开关 |

日志里每道题都会标注来源：`[本地题库]`、`[网课小助手]`、`[AI]`，方便你核对答案靠不靠谱。

---

## 出问题怎么办

1. **多选题没选上** → **🔬 导出题目 HTML**，把剪贴板内容发出来。
2. **题库一直没命中 / 报流控** → 点 **🔌 测试题库**；或取消勾选「免费题库」改用纯 AI。
3. **任务点或"下一节"点错** → **🧭 扫描自检** 看候选，再用 🎯 拾取校准。
4. 详细过程看 `F12` 控制台里的 `[DS答题]`。
