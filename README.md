# 学习通（超星）Tampermonkey 用户脚本

两个互相独立的脚本：一个负责**刷课进度**（把视频 / 音频 / 文档 / 图片任务点过完），一个负责**做题**（章节测验、作业）。可以只装一个，也可以两个都装。

| 脚本 | 版本 | 干什么 | 详细说明 |
| --- | --- | --- | --- |
| [`xuexitong刷客-GitHub融合版.user.js`](./xuexitong刷客-GitHub融合版.user.js) | 3.0.0 | 章节任务点自动完成：视频 / 音频 / 文档 / 图片逐个过，多视频连播，完成状态校验，自动进入下一节。深色「顺序播放」小面板，随时启动 / 停止。**默认原速、跳过测验、不答题**；检测到人脸 / 滑块验证自动暂停。 | [刷课说明](./刷课说明.md) |
| [`学习通-DeepSeek自动答题器.user.js`](./学习通-DeepSeek自动答题器.user.js) | 3.8.8 | 章节测验 / 作业自动答题：本地题库 → 免费公开题库 → 自定义题库 → DeepSeek 兜底。字体加密题自动截图识别，自动提交、自动进入下一小节。 | [答题器说明](./答题器说明.md) · [更新记录](./CHANGELOG.md) |

## 怎么配合用

1. 先装**刷课脚本**，把章节里的视频 / 文档任务点刷完（它默认跳过测验，不会乱答题）。
2. 再装**答题器**，打开同一章节，它会去找「章节测验」任务点做题。
3. 两边都不改平台数据、不带账号信息；答题器需要你自己的 DeepSeek API Key。

⚠️ 不建议两个脚本同时启动：刷课脚本负责推进「下一节」，答题器也负责推进，同时跑可能互相打断。建议刷完课先点「停止」，再启动答题器。

## 安装

Tampermonkey（篡改猴）→ 新建脚本 → 全选粘贴本文件内容保存；或直接从 raw 链接安装。

> 本仓库目前是 **私有仓库**，raw 链接需要先在浏览器登录 GitHub 才能拿到脚本。想免登录安装，把仓库改成 Public 即可。

## 风险与免责

- 仅用于个人学习研究。学习通对刷课 / 自动答题有行为检测（播放行为、答题行为、答题时长），使用风险自负。
- 答题准确率不保证：题库是公开第三方接口，命中不了就交给 AI，AI 也会错。**学分课、期末考试请自己动手。**
- API Key 只存在浏览器本地存储（localStorage / GM 存储），不会出现在本仓库里。
