# 学习通（超星）自动答题器

> **当前最新版本：`v3.8.7`**
> 主文件：`学习通-DeepSeek自动答题器.user.js`
> 每个历史版本在 git 里都有对应的 commit 和 tag。

---

## 这是什么

一个篡改猴（Tampermonkey）用户脚本，用在学习通（超星）的章节学习页：

- **题库优先**：先查题库，命中直接搬答案；查不到才调 DeepSeek
- 自动识别题目（单选 / 多选 / 判断 / 填空，简答题可开关），字体加密题自动截图走视觉识别
- 自动提交、自动进入下一个小节
- 视频任务点**不碰播放器**，先点开同小节的「2 章节测验」任务点，答完再点「下一节」
- 找不到下一节 → 判定本课程结束，停在当前页

## ⚠️ 两个高频问题怎么排查（先看这里）

### 1. 题库"全都找不到"

**第一步：点面板上的 `🔌 测试题库`**，日志会明确告诉你是哪一类：

| 日志 | 含义 | 怎么办 |
|---|---|---|
| `免费题库可用（网课小助手）：…` | 接口正常 | 若仍查不到，是这门课的题不在免费库里 → 靠本地库积累或等 AI |
| `题库查询失败：网络错误/请求超时/HTTP xxx` | **请求根本没成功** | 检查能否打开 `https://cx.icodef.com`；Tampermonkey 是否拦了跨域；换网络重试 |
| `题库查询失败：响应非 JSON：…` | 拿回来的是网页不是数据 | 大概率被运营商/防火墙劫持，贴日志给助手 |
| `题库查询失败：流控(code:-2)` | 触发 1 并发限制 | 等 10 秒自动冷却，或调大间隔 |
| `题库未收录(code:-1)` | 接口正常，但这道题它没有 | 正常现象，会自动交给 AI |

启动后日志里还会打印 **`题库查询文本示例：…`**，可以据此确认发出去的题干是不是正常的（不该带选项内容）。
连续 2 次请求失败会自动放弃题库、本轮全交给 AI，不会一直卡着。

> **v3.4.1 修复**：上一版「🔌 测试题库」在没点启动时直接返回「已停止」（耗时 1ms），**根本没发出请求**，
> 所以看起来像"题库全都查不到"。现在测试按钮不再依赖任务是否启动。

### 2. 多选题"点了选不上"（v3.6.0 已根治）

> **根因**：`nativeClick()` 同时做了「合成 click 事件」和 `el.click()`，等于**连点两次**。
> 单选 radio 点两次结果一样（幂等），所以一直正常；多选 checkbox 点两次 = 选上又取消，
> 所以"怎么点都选不上"。v3.6.0 改为只派发一次 click，并从 `li` 的 `onclick` 属性里
> 发现页面自己的作答函数（`addChoice` / `addMultipleChoice`）直接调用一次。
> 选中判定也改为优先读页面自己的隐藏答案框 `input[name="answer<qid>"]`。

**v3.4.0 还做了下面三项兜底：**

v3.4.0 针对三个最可能的原因做了修复：

- **连点抵消**：同一个选项短时间内被点两次 = 刚选上又被取消。现在 600ms 内不会重复点。
- **节点失效**：学习通新版是 JS 渲染，点一个选项后整段可能重新渲染，之前缓存的节点就失效了，
  后续点击等于点在空气上。现在每次点击前都会确认节点还在，失效就重新采集。
- **识别器漏判导致反复点击**：不再只看"单个选项认不认得出"，而是比对**整题选中态有没有变化**；
  只要点击产生了变化就认为生效，不会再去点第二次。

如果还是不行：**点 `🔬 导出题目 HTML`**，它会打印每道题的真实结构，包括
`li.class` / `aria-checked` / `aria-pressed` / 隐藏答案框的 value / 字母标记元素，
把复制出来的内容发出来就能精确定位。

### 解密失败怎么排查（v3.7.1）

日志会按阶段打印，看到哪一步停住就知道原因：

| 日志 | 含义 |
|---|---|
| `字体解密：当前页未发现混淆元素（扫描 N 个文档）` | DOM 里没有 `.font-cxsecret`，不需要解密（正常） |
| `字体解密：找到内嵌字体（base64 XXX KB），开始还原…` | 字体找到了，正在算映射 |
| `字体解密：建立映射 N 个码位` → `字体混淆已解密（N 处替换）` | 成功，题干已变真字 |
| `字体解密失败：没在任何 <style> 里找到内嵌的混淆字体(base64)` | 字体可能在其它 frame 或用了外链字体 |
| `字体解密失败：Typr 字体解析库加载失败（CDN 不通？）` | jsdelivr 被墙/被拦 |
| `字体解密失败：字体映射表 table.json 不可用` | forestpolice.org 下载失败 |
| `字体解密失败：映射表里对不上这个字体（字体可能换新版了）` | 学习通换了字体，映射表没收录该字形 |

任何一步失败都会自动退回「截图 + 视觉模型」路径，不影响答题，只是题库拿不到真题干。
## 完整处理链路（v3.8.0）

```
取题
 ├─ 字体混淆？ ──是──→ ① 字形 hash 查表解密（纯查表，不用 AI）
 │                        └─ 解不开 → ② 截图 + 视觉模型「只转写文字」（不答题）
 │                                        └─ 转写失败 → 保持截图，走视觉答题
 └─ 得到真实题干文字
        ↓
   ③ 题库检索（本地 → 自定义 → 一之题库 → free4）
        ├─ 命中 → 直接搬答案
        └─ 未命中 → ④ DeepSeek 用真人文字作答（文本请求，比视觉便宜也更准）
        ↓
   ⑤ 自动点击作答（单次派发、防连点、隐藏答案框校验）→ 自动提交 → 下一节
```

关键点：**题库检索永远只认真实文字**。所以字体解密或视觉转写必须先成功，否则题库拿到的是乱码，必然 0 命中。
## 字体混淆（font-cxsecret）是怎么处理的

学习通会把题干和选项用**自定义字体**渲染成随机码位，DOM 里读出来是「扞扚扖扝」这种乱码。
如果不处理，题库按文本永远查不到，AI 也读不懂题干。

处理方式（与「满分助手」同源，**纯查表、不消耗 AI**）：

1. 页面 `<style>` 里内嵌着 `@font-face` 的 base64 字体；
2. 用 Typr 解析这份字体，对 CJK 区每个码位算出**字形轮廓**；
3. 轮廓 JSON 取 **md5 前 24 位** → 查 `table.json` 映射表 → 得到真实汉字；
4. 把 `.font-cxsecret` 元素的文字替换成真字并移除该类名。

还原后 `collectQuestions` 拿到的就是真实文本，**题库检索和 AI 提示词用的都是真字**。
如果依赖加载失败（CDN 不通/表下载失败），自动退回原来的「截图 + 视觉模型」路径，不影响答题。

## 题库策略

检索顺序：

```
本地题库 → 自定义题库 → 免费公开题库 → DeepSeek 兜底
```

| 层 | 说明 | 默认 |
|---|---|---|
| **本地题库** | 自动收录答过的题（存「选项文本」，选项顺序变了也能对上），跨学习通子域共享 | 开 |
| **自定义题库** | 填一个兼容 `POST /api/search` 的地址（`chaoxing-toolkit` 协议），留空则跳过 | 未配置 |
| **免费公开题库** | 主源「一之题库」`cx.icodef.com` + 备用源 `free4`（muketool），均免 token，取自「满分助手 2.1.6」的真实搜题逻辑 | 开 |
| **AI** | DeepSeek，前三层都没命中才用 | 已有 |

### 关于免费公开题库（务必知道）

- 它**不是**学习通官方题库。学习通没有公开的官方题库/API。
- 主源是「一之题库」`POST https://cx.icodef.com/wyn-nb?v=4`，`{"question":"题干"}` → `{"code":1,"data":"答案1#答案2"}`，免 token。
  实测公共课题目抽样命中约 5/6。
- **会返还"广告占位"当作答案**，例如 `李恒雅奋力撰写中…(未搜索到答案)`、`请关注公众号…`、`本题答案在付费题库中`。
  脚本已按参考实现的关键词过滤这类内容，当作"未收录"处理。
- **有 1 并发限制**：实测 0ms 连发第 3 条就 `code:-2 流控`；1.5~2.5s 间隔连续 4 条无流控。
  脚本取 **2s** 间隔 + 8s 流控冷却；随机 `X-Forwarded-For` 实测**不能**绕过该限制。
- 备用源 `https://api.muketool.com/cx/v2/query`（free4，免 token）。部分网络被 Cloudflare 拦（error 1033），
  连续失败 3 次会自动停用，不影响主源。
- 是第三方接口，**可能随时失效、也可能返回错误答案**。面板可取消勾选「免费题库」退回纯 AI。
- 代价：一节课题越多越慢（每题约 2s）。已限制单轮最多查 24 题。

## 快速开始

1. 浏览器安装 **篡改猴（Tampermonkey）**扩展。
2. 篡改猴 → 打开原脚本 → **全选清空** → 粘贴本目录下 `学习通-DeepSeek自动答题器.user.js` 全部内容 → `Ctrl+S`。
   > ⚠️ **不要新旧两个脚本同时安装**，会双重点击同一道题。
3. 打开学习通课程页，面板里填 DeepSeek API Key（`sk-` 开头）→「保存」。
4. 建议先点 **🔌 测试题库** 确认连通性。
5. 点「▶ 启动」。第一次请求时篡改猴会弹跨域授权，选「始终允许」。
