# 学习通（超星）自动答题器

> **当前最新版本：`v3.2.0`**
> 主文件：`学习通-DeepSeek自动答题器.user.js`
> 每个历史版本在 git 里都有对应的 commit 和 tag（`v2.1.0` / `v3.0.0` / `v3.1.0` / `v3.2.0`）。

---

## 这是什么

一个篡改猴（Tampermonkey）用户脚本，用在学习通（超星）的章节学习页：

- 自动识别页面上的题目，调用 **DeepSeek** 作答（单选题 / 多选题 / 判断题 / 填空题，简答题可开关）
- 字体加密题（`font-cxsecret`）自动截图走视觉识别
- 自动提交、自动进入下一个小节
- 视频任务点**不碰播放器**，只负责跳过：先点开同小节的「2 章节测验」任务点，答完再点「下一节」
- 找不到下一节 → 判定本课程结束，停在当前页

---

## 快速开始

1. 浏览器安装 **篡改猴（Tampermonkey）**扩展。
2. 打开篡改猴 → 新建脚本（或打开原来那个脚本）→ **全选清空** → 粘贴本目录下
   `学习通-DeepSeek自动答题器.user.js` 的全部内容 → `Ctrl+S` 保存。
   > ⚠️ **不要新旧两个脚本同时安装**，会双重点击同一道题。
3. 打开学习通课程页面，右上角面板里填入 DeepSeek API Key（`sk-` 开头），点「保存」。
   Key 只存在浏览器 localStorage，不会发给第三方。
4. 点「▶ 启动」。第一次请求 API 时篡改猴会弹跨域授权，选「始终允许」。

## 面板按钮

| 按钮 | 作用 |
|---|---|
| ▶ 启动 / ■ 停止 | 开始 / 停止自动答题 |
| 🔍 诊断本题 | 打印某道题的选项状态、绑定事件，用于排查"点了没反应" |
| 🧭 扫描自检 | 列出所有 frame、是否判定为视频页、**未完成任务点标签**、**下一节候选及排序理由** |
| 🔬 导出题目 HTML | 把前 3 道题的真实 DOM 复制到剪贴板；**多选题出问题就点它**，把内容发出来即可定位 |
| 🎯 拾取「下一节」 | 手动绑定"下一节"按钮（优先级最高，学习通改版时用） |
| 🎯 拾取「章节测验」 | 手动绑定任务点标签 |
| 清除所有手动拾取 | 恢复自动识别 |

---

## 出问题怎么办

1. **多选题没选上** → 点 **🔬 导出题目 HTML**，把剪贴板内容发出来（里面含题块真实结构、每个选项的 `input`/`class`/`aria` 状态）。
2. **任务点或"下一节"点错** → 点 **🧭 扫描自检**，报告里会说明每个候选为什么被选中/排除；确认后用 🎯 拾取校准。
3. 想看详细过程 → 按 `F12`，控制台里搜 `[DS答题]`。

## 本地回归测试

脚本改动后建议跑一遍（不需要学习通账号，用仿真页面验证）：

```bat
:: 窗口 1
node test\server.js

:: 窗口 2
run-headless.bat
```

跑完看 `dom-nav.txt` 和 `dom-quiz.txt` 里的 `===TEST-START===` 段落，
应显示「合计 N 项，失败 0 项」。当前共 **53 项断言**：
- 导航类 25 项：目录/左侧栏诱饵是否被排除、下一节候选排序、点错拉黑换人、任务点标签识别与切换
- 多选类 28 项：答案格式解析、题型识别、多选不被顶掉、隐藏答案框并集累加、多选没选全的补选闭环
